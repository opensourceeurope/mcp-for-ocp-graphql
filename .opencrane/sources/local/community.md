# `community` query

Returns `AccountCollection!`.

Return accounts that have interacted with a given account or host

Arguments: `account` (AccountReferenceInput), `host` (AccountReferenceInput!, required), `type` ([AccountType]), `searchTerm` (String), `relation` ([CommunityRelationType!]), `missingInformation` ([MissingInformationField!]), `orderBy` (OrderByInput), `totalContributed` (AmountRangeWithYearInput), `totalExpended` (AmountRangeWithYearInput), `limit` (Int!), `offset` (Int!).
