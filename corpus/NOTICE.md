# Corpus Attribution Notice

The RAG corpus is regenerated by `.github/workflows/corpus-refresh.yml` with
OpenCrane and committed under `.opencrane/sources/`. It combines three kinds of
source, attributed below.

## Open Collective GraphQL Documentation

The guides fetched into `.opencrane/sources/opencollective/graphql-docs-v2/`
(`pages/01.Welcome.md` … `pages/03.First Queries/*.md`) come from:

> https://github.com/opencollective/graphql-docs-v2

Original content copyright Open Collective, Inc. and contributors.
Licensed under the terms of the upstream repository.
These files are indexed for local RAG search only.

## Schema Reference

`.opencrane/sources/local/schema-reference.md` is generated at build time from the
Open Collective GraphQL API introspection schema
(`mcp_for_ocp_graphql/data/schema.json`) via
`python -m mcp_for_ocp_graphql.schema_ref`. The schema is the property of
Open Collective, Inc.

## Querying Skill

`.opencrane/sources/local/querying-skill.md` is a build-time copy of
`.claude/skills/querying-opencollective-graphql/SKILL.md`, project-internal
documentation authored by the maintainers of this repository. That skill file is
the single source of truth; the corpus copy is regenerated on each refresh.
